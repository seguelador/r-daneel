# archive/ — closed work

Where finished and stale things go so the live layers stay honest:

- Closed tracks (a project shipped or abandoned).
- Dead projects (e.g. a team you moved off of).
- Old prep artifacts and swept-out `tasks.md` "Completed" items.

Move things here instead of deleting them — the history stays queryable, but
it's out of the way of "what am I working on now". Keep the original path in a
one-line note when it helps (e.g. `was projects/<epic>/<track>.md`).
