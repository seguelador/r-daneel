# prep/ — ephemeral prep

Meeting prep, talking points, and the `/braindump` inbox live here. This is a
**holding pen, not a destination**:

- `/prep` and `/notas` generate prep artifacts here.
- `/braindump` appends to `prep/inbox.md`.
- On the next `/sync` or `/catchup`, the **durable residue** (decisions, action
  items, context) is routed to its real home (a track, a `team/` dossier,
  `tasks.md`, `growth/`), and the prep artifact is archived or discarded.

Nothing durable should live only here.
